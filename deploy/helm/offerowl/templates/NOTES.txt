Open the panel
  The panel has no login and holds your profile and documents, so nothing is exposed. Forward its port to the machine
  you sit at, using the same port number on both sides (the panel answers only requests addressed to its own port):
{{ range $c := $h.instances }}
    {{ with $c.Tenant }}{{ . }}: {{ end }}kubectl --namespace {{ $ns }} port-forward svc/{{ include "offerowl.instanceName" $c }} {{ $panel }}:{{ $panel }}
{{- end }}

  and open http://127.0.0.1:{{ $panel }} in a browser on that machine; an application's interview kit is on the same
  port, at /kit/<job>/. Keep the forward on 127.0.0.1, the default: --address 0.0.0.0 would open the panel to your network.
{{- if .Values.tenants }}
  One forward at a time on this port: every person's panel answers its own port, the same number for all.
{{- end }}

Check it
    helm test {{ .Release.Name }} --namespace {{ $ns }}
