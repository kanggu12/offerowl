# 델타페이 백엔드 플랫폼 엔지니어 채용 공고 (가상의 예제)

이 공고는 Offerowl 의 시험과 설명에 쓰는 가상의 글이다. 실제 회사와 관계없다.

```
백엔드 플랫폼 엔지니어

델타페이는 가맹점과 소비자를 잇는 간편결제 서비스를 운영합니다. 결제가 멈추면 곧바로 손실로 이어지기 때문에 승인 경로의 안정성과 배포 체계를 가장 중요하게 봅니다.
플랫폼팀은 결제 서비스 개발자가 쓰는 배포, 관측, 장애 대응 도구를 함께 만들고 운영합니다.

주요 업무
- 결제 승인과 정산 백엔드 서비스의 설계와 개발
- 서비스 사이를 잇는 이벤트 기반 연동 설계와 운영
- Kubernetes 기반 배포 파이프라인과 사내 개발자 플랫폼 운영
- 서비스 지표와 알림 체계 구축
- 장애 대응 절차 수립과 당번 운영
- Rust 로 작성하는 결제 단말 펌웨어 개발

자격 요건
- 백엔드 서비스 개발과 운영 경력 3년 이상
- Go 또는 Java 로 서비스를 운영한 경험
- Kubernetes 운영 경험
- 관계형 데이터베이스 설계 경험

우대 사항
- Argo CD 나 Helm 으로 배포 환경을 관리한 경험
- 결제 도메인 경험
- Terraform 으로 인프라를 코드로 관리한 경험
- 정보보안기사 자격

근무 조건
- 서울 근무
```
