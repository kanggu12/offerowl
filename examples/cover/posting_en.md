# Orion Payments backend platform engineer posting (fictional example)

This posting is invented for Offerowl's tests and docs. It describes no real company.

```
Backend Platform Engineer

At Orion Payments we run a payment service that connects merchants and shoppers. When payments stop, money is lost at once, so we care most about the stability of the approval path and about how we ship changes.
The platform team builds and runs the deployment, observability and incident tools that the payment developers use.

Responsibilities
- Design and build the backend services for payment approval and settlement
- Design and run event-driven links between services
- Run the Kubernetes deployment pipeline and the internal developer platform
- Build service metrics and alerting
- Set up incident response and take part in the on-call rotation
- Write firmware in Rust for payment terminals

Qualifications
- 3+ years building and running backend services
- Experience running services in Go or Java
- Experience running Kubernetes
- Experience designing relational databases
- Able to work with colleagues in English

Preferred Qualifications
- Managing deployment environments with Argo CD or Helm
- Experience in the payments domain
- Managing infrastructure as code with Terraform
- A security certification such as CISSP

Location
Seoul, hybrid
```
