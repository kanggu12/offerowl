# Gamma Cloud: Platform Engineer, Payments Infrastructure

A fictional job posting for the interview kit example. Gamma Cloud and every detail below are made up.

## About the team

Gamma Cloud runs the payment platform behind several online stores. The platform team owns the deploy path, the event
pipelines and the reliability of payment approvals.

## What you will do

- Build and run the Kubernetes deployment platform that our payment teams share
- Design GitOps release paths with Argo CD and Helm, with review and rollback
- Keep payment approval services reliable with idempotent APIs, retries and timeouts
- Run Kafka event pipelines between orders, settlement and notifications
- Lead incident response and write runbooks that new engineers can follow
- Work with product teams to move manual operations into automation

## What we look for

- Experience building backend or platform systems in Go or Java
- Hands-on experience with Kubernetes, Helm and a GitOps tool
- Experience running PostgreSQL, Redis and Kafka in production
- Clear written communication in English and Korean

## Nice to have

- Terraform and infrastructure as code
- Observability with Prometheus, Grafana or OpenTelemetry
- Experience in payments or e-commerce
